More answers

1. Which formats are supported in all modern browsers?
Answer: All modern browsers support JPEG, PNG, GIF, SVG, and WebP.

2. Why would you use SVG instead of JPEG for a logo?
Answer: SVG is a vector format, which means it can scale to any size without losing quality.
It also has smaller file sizes for simple graphics and looks sharp on all screens.
JPEG is a raster format and loses quality when resized, so it is not ideal for logos.

3. What advantage does the WEBP format have compared to PNG and JPEG?
Answer: WEBP provides better compression, meaning files are smaller while still maintaining high quality.
It supports lossy and losseless compression, transparency, and animation. So it can replace both PNG and JPEG while using less space.

4. Does GIF support transparency and animation? What about PNG? How do they differ?
Answer: GIF Supports both animation and 1-bit transparency but it is limited to 256 colors.
PNG Does not support animation but supports full alpha transparency and better color quality.
The main difference is that GIF supports animation, PNG supports high-quality transparency.

5. Which formats allow lossless compression?
Answer: The following formats support lossless compression:
PNG, GIF, SVG (vector, inherently lossless), and WebP (in lossless mode).
